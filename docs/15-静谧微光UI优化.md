# 静谧微光 UI 落地

依据用户提供的 UI 结构提案优化现有界面，以当前 21 关及已经实现的实体第四章为准；没有照搬提案中的旧关卡数量或抽象第四章图。

底部操作区采用 48 CSS 像素单行。参数按钮切换到同一行中的角度/缩放控件，再用“工具”返回；不增加第二行，不移动场景或改变命中坐标。本关没有的工具隐藏，运行时收起编辑工具，保留返回准备。清空与重置从常驻栏移除，暂停菜单中的清空需要再次确认。时间移入暂停与结算，计分规则不变。

采用深林底色、月光文字、浅芽动作色；中文标题采用系统宋体回退，不增加外部字体下载。选关卡片沿章节路径显示完成/锁定状态；详情改为右侧可滚动面板。设置默认展示独立音效与触觉开关，隐藏原总开关。教学指引保留，正式关常驻提示收成右上角帮助按钮。

关卡、物理、音效和 BGM 内容保持不变，第四章实体场景保留。尚未增加跨会话建造草稿或自动失败诊断，不对这些能力作出承诺。

验证：npm test；node tests/browser.cjs --quiet-ui。浏览器检查 1440×900、960×432、800×360 下的单行高度、参数切换、清空确认和恢复。截图保存在 tests/artifacts，不替代 Android 真机验证。
