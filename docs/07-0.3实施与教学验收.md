## 恢复与版本范围

按用户要求，从 Git 提交 `a9573d4（重力初版）` 恢复昨晚的固定向下重力代码，并继续调整。恢复涉及游戏、关卡、测试和设计文档；保留当前 DCloud AppID、Android 包名等配置，版本更新为 `0.3.0 / 300`，移除不再使用的加速度计模块和无效的 iOS 发布配置。

## 教学与难度递进

原第二关同时要求理解配重、弹射轨迹、出口板位置和角度，缺少明确操作目标。本次把新知识拆开：

| 阶段 | 新增内容 | 引导与容错 |
| --- | --- | --- |
| 教学1：第一道斜坡 | 放一块木板并释放 | 角度预先调好；虚线板显示目标，100逻辑像素范围内自动对齐；不用先学旋转 |
| 教学2：配重的力量 | 拖一块配重，观察跷跷板 | 出口桥预先搭好，隐藏板/线工具；源方块高亮、箭头连接到金色目标；95逻辑像素范围内吸附到承托位 |
| 教学3：画一段归途 | 画一笔导流坡 | 虚线与起止圆点示意；不引入缩放，不需要同时调两种工具 |
| 第一章 | 自己旋转木板、组合配重与出口桥、开关、弹簧 | 撤去教学吸附，沿用学过的操作，逐步组合机关 |
| 第二章 | 两板跨缺口、自由画线、缩放穿缝、滑轮和堆叠 | 缩放首次出现在2-3，提供按钮与手势说明；摆放区、合法性预览和操作提示继续保留 |
| 第三章 | 时序、固定升流井、水流与染洗顺序 | 固定设施显示范围和方向，提示说明所需入口、出口及顺序 |

每个教学都有随真实配置更新的三步文字：**放置/画线 → 点击释放 → 观察因果**。桌面显示进度条并高亮当前工具或释放按钮；手机通过顶部步骤文字显示进度，隐藏会遮挡配重的重复底部条。准备阶段可重试、撤销和清理，`?` 可重看指引。教学三星时限放宽到5分钟。

教学吸附只辅助准备阶段的合法摆放，仍检查碰撞、区域和支撑；不直接搬球、不修改重力、不注入通关。正式关没有这套吸附到指定解位置的辅助。

## 运行与维护

### 第一章试玩反馈后的重做（2026-11-02）

旧版「光的回声」实际只有压力开关，名字与玩法不符；旧版「万物相连」复用跷跷板关，弹簧与出口道路重叠且可被忽略。已删除这两处布局中的无关机关，按以下学习顺序重做：

| 关卡 | 名字对应的行为 | 承接与新增知识 |
| --- | --- | --- |
| 微光的轨迹 | 用斜坡改变发光小球的轨迹 | 从序章自动对齐过渡到自己旋转搭桥 |
| 两端之间 | 配重端下沉，球端上升 | 组合序章配重与上一关的出口桥 |
| 光的回声 | 球穿光束，远处的门亮起并回应 | 复用单板桥，只新增一次触发、持续开门的光联动；不要求抢时间 |
| 向上的可能 | 弹簧提供向上的动力，桥面承接 | 复用桥面，只新增固定弹簧的轨迹判断 |
| 万物相连 | 弹簧 → 导流线 → 光束 → 门 → 收集器 | 综合序章画线、第三关光门、第四关弹簧，不增加新操作 |

光门的连接在准备阶段就可见，触发后连线点亮，门标为已响应；弹簧有实体名称及托送方向。第三、第五关增加准备、检查、运行观察的分步提示。第五关的弹簧放在低处独立落点，建造区在高处承接段，避免旧版道路重叠。

新增15项回归：第三至第五关分别移除承接、断开光束、取消弹簧动力（按关卡适用），正向与镜像均不能入仓；检查第五关实际事件按弹簧、光门、通关发生，以及弹簧与地形无碰撞重叠。所有33个普通/镜像正例仍通过。反例针对这些布局及回放，不声称穷尽所有自由画线方案。

浏览器新增真实鼠标验证：第三关旋转14°并放板、第五关实际拖动画线，释放后均通关且光门确实激活。截图 `06-light-echo.png`、`07-connected-route.png` 已复核，弹簧与道路分离，光束连线及提示可见。另手动运行物理回放，将第五关参考线整体上下平移6或12逻辑像素，四种画法均合法且通关。

后续关卡设计以此为准：每关先写清名称对应的可观察行为；新增机关先单独教，再在后关组合；每个机关必须承担动力、承接、控制或明确的可选奖励作用；主路径机关需验证移除后的结果；传感光束穿过道路属于预期检测关系，实体机关相互穿插必须排除。不能仅凭参考解能通关就认定关卡设计通过验收。

### 本地启动

双击根目录 `play.html` 即可离线试玩；或执行 `node scripts/serve.cjs`，访问 `http://127.0.0.1:8765/play.html`。固定一种入口保留同源存档。0.2成绩归档可在设置查看，新规则成绩分开记录。

编辑 `static/game/data/levels.json` 后执行 `node scripts/build-levels.cjs`。若改动关卡生成脚本，可执行 `node scripts/create-levels-v3.cjs` 同步重生关卡与正例fixture；之后重新生成离线脚本并回归。该命令会覆盖源JSON，直接手改JSON时不要无意重生。

`docs/03`、`docs/04` 保留0.2历史，`docs/06` 保留昨晚暂停快照；当前实现与验证范围以本文件为准。

管理员模式：设置中新增默认关闭的开关，持久化保存，开启可进入全部普通与镜像关；关闭恢复进度门槛。新增回归验证开关、重新载入和真实成绩/碎片保留，测试总数91。
