# 第二、三章：关卡主题与递进审查

日期：2026-11-02。按第一章试玩反馈的标准检查全部10关：名称须对应可观察的行为，新关须有新增问题，综合关须说明组合了什么，主路线机关必须有实际作用。

## 发现与处理

旧版2-2复用了序章画线缺口；3-1可用配重永久开门绕过时限；3-3只给普通斜坡加速；3-4和3-5基本相同，末关水流可忽略，洗色区设在失败落点附近，作用不明确。堆叠关还留着与任务无关的小球、收集器数据和画线库存。

保留有独立主题的双板、缩放、滑轮、升流井和堆叠，重做重复或可绕过主题的路线。堆叠关删除小球与画线库存/建造区，运行和界面支持无球的纯堆叠任务；收集器仅保留兼容配置，不渲染、不参与目标判定，胜利反馈在堆叠区显示。

## 第三章：光的回廊

| 关卡 | 名称与实际任务 | 相对已学内容的递进 |
| --- | --- | --- |
| 光门的时限 | 光束触发后只开放4秒，必须选连续下坡路线及时过门 | 从第一章永久开门过渡到路线耗时；移除永久保持的压力开关，显示倒计时 |
| 乘流而上 | 沿入口导坡进入升流井，在上方出口用板承接 | 原名“逆流而上”与顺着升流上升不符；保留局部固定升流及必要的两端承接，全局重力仍向下 |
| 水流的方向 | 水流推动水平河床上的静止小球，搭出口桥续接 | 水流提供必要的水平起步动力；删除水流后不能靠坡度自行出发 |
| 三色回廊 | 分段路线依次经过红、黄、蓝，最后洗回白色入仓 | 复用第二章分段承接，新增当前颜色与经过记录的区别；洗色保留顺序记录，白色收集器要求当前颜色为白色 |
| 回廊的回声 | 水流启动、双板长桥接力、三色齐备后门回应4秒，洗白入仓 | 综合第二章双板与本章动力、颜色、时限；采用水平河床加宽缺口，区别于上一关的双缺口画线；无新操作 |

第三章最后两关不是要求玩家猜隐藏颜色条件：顶部显示三色顺序，传感区标注颜色/洗色，收集器明确标为白色并使用白色描边，末关门标注三色齐备才回应。全部10关提供准备、检查、运行观察三阶段说明。镜像水流箭头随实际方向翻转。

## 验证证据

- `npm test`：133项通过，包含18普通关及15镜像关公开准备操作后释放通关，15个正式关碎片均能由参考路线取得。
- 新增反例覆盖缩放、滑轮、升流井、水流、光门连接、每种颜色、洗色、桥面；对应普通和镜像均不能在移除关键环节后照常通关。末关任一桥板缺失也无法完成。堆叠只放任意两个方块不能完成。
- 时限对照：3-1使用同一合法较慢桥面（中心890/670、角度0.4弧度），永久开门时通过，四秒门时被挡住；普通与镜像一致。不是只检查配置里写了“四秒”。
- `node tests/browser.cjs`：真实鼠标完成2-2、3-1、3-3、3-4、3-5，使用实际画线、旋转、放板和释放操作。保留第一章与序章回归、手机触摸三层堆叠、暂停/存档/离线入口检查。
- 截图保存在忽略提交的 `tests/artifacts/`：`ch2_l02-preparation.png`、`ch3_l01-countdown.png`、`ch3_l03-preparation.png`、`ch3_l04-preparation.png`、`ch3_l05-preparation.png`。已复核倒计时、颜色站、白色终点与末关布局。
- 工程预检、修改脚本语法检查和 `git diff --check` 通过。未进行本轮APK构建或手机真机性能验收。

最终视觉复测中，关卡与手机操作均通过，离线入口脚本偶发在 `play.html` 自动跳转前点击旧页面控件。已将等待条件改为最终文件地址和游戏按钮初始化完成，并以 `node tests/browser.cjs --offline-only` 单独复测通过；这是测试等待修正，未改动游戏的离线入口行为。

有限反例证明主题机关在这些路线中有作用，并不穷尽自由构筑的所有解法。不同玩家的操作难度仍需试玩；不得把自动回放成功等同于所有玩家都能直观理解。后续调整应同时保留名称对应、教学说明和移除关键机关的对照验证。

## 修改入口

关卡布局和参考准备操作在 `scripts/create-levels-v3.cjs`；运行该脚本会同步重生JSON与fixtures，再运行 `scripts/build-levels.cjs` 更新离线游戏数据。不要只修改编译出的 `static/game/js/levels.js`。
