# 失衡空间 0.2 开发修订与验收说明

日期：2026-11-01。输入为 `01-需求分析文档.md`（SRS 1.1）、`02-游戏设计文档.md`（GDD / SDS 1.1）与 0.1 Demo。用户已授权修改不合理的设计；本文件记录实施后的规则。以下条目与旧文冲突时，以本文件描述的 0.2 行为为准。未列出的未完成项不自动视为验收通过。

## 设计修订

| 涉及需求 / 设计 | 调整后的规则 | 理由与实现 |
| --- | --- | --- |
| FR-20 滑轮、原验收中的 2:1 速度 | 两端等距、反向；总绳长不变，质量差改变加速度 | 定滑轮不产生速度倍率。由物理层对质量加权位置/速度投影，托盘可承接球；不是完整绳索柔体模拟 |
| FR-39 稳定堆叠与 FR-27 禁止拖刚体 | 仅标记 draggable 的任务方块可直接拖动，松手恢复物理；球依然不能直接拖拽 | 原方案没有明确可控的堆叠输入。使用约束拖拽；全部方块完整进入目标框、低线速度/角速度并稳定 3 秒才成功，拖拽时不累计 |
| SEC-1 / SEC-6 页面和节点画布 | uni-app Vue3 页面内嵌随包本地 WebView，游戏使用标准 Canvas 2D；主入口恢复标准 Vue 启动 | 在 H5 与 App 复用同一渲染/触摸代码；本地资源是官方支持的 WebView 用法。游戏状态留在 WebView，不参与跨层响应式更新 |
| FR-41 存储与迁移 | App 使用 plus.storage，H5 使用 localStorage；v1→v2、上次备份、坏档隔离、失败重试 | 本地 WebView 不直接依赖外层 Vue 的同步 uni storage。将平台差异收敛到 platform.js，避免依赖 file-origin 浏览器缓存 |
| FR-14 / NFR-04 滤波时间 | 指数滤波时间常数 120ms，按实际步长计算；死区 0.026；支持中立校准 | 原 0.2–0.5 秒时间常数与 150ms 延迟目标冲突。采样仍可能受设备限制，实际端到端延迟必须真机测量 |
| FR-30 水流与缩放红线 | 水流施加质量无关的加速度，边界 45 像素内平滑混合；局部重力替代全局重力 | 避免轻球无故受到更大加速度。它是清晰可控的游戏力场，不宣称流体仿真 |
| FR-19 / FR-21 门和弹簧 | 门是围绕铰点的受控执行器；弹簧是接触触发、限速、有冷却的弹射面 | 减少约束能量发散；支持 Link 四语义。未实现碰撞自由推门与材料级弹簧压缩，不冒充精密机械仿真 |
| FR-25 搭桥手势 | 点选木板后在场景拖放；触屏提供 15° 旋转按钮；木板落点固定 | 明确工具状态，避免库存区域与原生页面触摸冲突；可撤销返还 |
| FR-09 教学 | 三个教学关提供动态分步提示，不硬锁所有错误操作 | 保留探索及替代解；不以不可见规则阻止动作 |
| FR-43 倒映章 | 15 正式关镜像，坐标/角度/力场方向/目标区同步变换；缩减工具但至少保留 1 个已有工具，弹簧增益×0.9；独立 ID / 成绩 | 删除“收集球数+1但没有新增球”的无解风险，也不强制高灵敏度。只变换已验证数据，不引入新机制 |
| FR-43 / FM-11 静置判定 | 全部 33 关执行 10 秒零重力有限性检查；不使用“动态球位移必须<1px”作为加载拒绝条件 | 运动本来就是游戏的一部分，统一抖动阈值会误拒合法弹簧/滑轮关。参考操控另验证基础运输关存在解 |
| FR-40 调试 | 源 JSON 编辑 + 校验/编译脚本 + `?debug=1` 运行快照及暂停单步 | 采用适合当前工程规模的作者工作流；暂未做可视化拖拽地图编辑器 |
| NFR-13 双语 | 本版中文操作文案；英文作为视觉副标题 | 中英即时切换仍为未完成的低优先级功能 |

## 已实现的链路

- FR-01~10：横屏配置、宿主前后台暂停、最近关卡恢复入口、菜单/选关/HUD/设置/教程/结算。实际平台行为仍需要真机验证。
- FR-11~17：物理独立封装、实体、60Hz 固定步长、有限性保护、重力滤波/死区/灵敏度、设备倾斜和无数据降级。物理接触通过几何检测和封装查询消费，未公开完整 collisionStart/Active/End 事件总线作为外部 API。
- FR-18~23：杠杆、受控铰链门、等长滑轮、弹射板、once/hold/toggle/pulse、联动流光、顺序正确/错误反馈与可恢复进度。
- FR-24~32：密度守恒缩放、有限额木板/画线、两指仲裁、撤销/清理、激光染色/洗色、水流、局部重力和压力传感器。
- FR-33~39：球颜色保持、颜色过滤与拒绝、死亡区、整关重置、运输/顺序/稳定目标、配置化星级、稳定窗口。重置回关卡初始世界，不保存中途逐机关检查点。
- FR-40~43：JSON 数据驱动、入口校验、调试单步与快照、存档 v2 / v1 迁移、15 枚一次性永久碎片、15 个独立倒映关。

## 构建和验收边界

1. 根目录 `index.html` 为标准 Vue 入口；独立试玩改用 `play.html`。H5 与 App 资源由本机 HBuilderX `uniapp-cli-vite` 实际编译成功。
2. 静态 WebView 的 JS 在发行构建中额外转译，原始开发源码不为旧浏览器降级；App 不加载远程游戏或 CDN，统计功能关闭。
3. 仓库原 AppID 为占位值。云打包前必须在登录的 HBuilderX 中获取真实 DCloud AppID，并选择 Android 签名。`preflight --cloud` 会识别并阻止把占位配置误当作已准备好的云打包配置。
4. 没有提交云端打包、生成签名 APK 或执行真机安装。H5/App 编译通过不等于 Android/iOS 兼容验收通过。
5. 自动测试提供规则、合法参考操控、编译后 H5 页面和触摸输入的证据；不把关卡难度、音画手感、真实传感器时延和功耗称作已经自动验收。自由重力允许技巧性替代路径，后续可基于试玩反馈调整谜题约束。

运行方法、测试命令及 APK 云打包步骤见项目根目录 README.md。
