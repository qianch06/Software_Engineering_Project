# 失衡空间：科幻风 UI 改造说明

> 本文记录 UI 分支的历史改造。当中的自由重力、倒映关和旧关卡数量不再适用于当前 main。当前版本以 branch0 的 16 关、固定向下重力和准备／释放机制为准；最新合并说明见 [13-分支整合记录](13-分支整合记录.md)。

## 改造目标

将游戏整体视觉调整为未来科幻风，营造深空空间站与重力控制实验室氛围，同时保留现有玩法、操作和离线运行方式。

## 主要修改

- 主菜单：加入重力能量核心、轨道动画、空间网格、扫描线与实验状态信息。
- 关卡选择：将关卡呈现为实验节点，增加节点连接、完成状态和倒映实验区样式。
- 游戏 HUD：统一深空蓝背景、冰蓝强调色、科技面板、重力圆盘和工具栏样式。
- 暂停与设置：改为半透明全息科技面板，保留原有设置功能。
- 通关反馈：加入能量核心激活动画与实验数据归档文案。
- 场景配色：调整 Canvas 中平台、机关、能量球、收集器和碎片的显示颜色。
- 全局背景：同步更新应用、页面、状态栏和安全区域的深空蓝背景色。

## 连贯交互动效

- 按钮反馈：增加按压回弹、触点波纹、确认闪光和锁定节点抖动反馈。
- 勾选联动：设置页使用真实复选框，总反馈开关与音效、触觉开关支持全选、半选和同步更新。
- 叠卡展开：章节默认收起为叠卡，当前进度章节自动展开，支持平滑展开与键盘操作。
- 吸附与画线：选关页滚动吸附到页头和章节，实验节点之间使用 SVG 路径连线并绘制展开动画。
- 惯性滚轮：滚轮输入带速度累积和阻尼减速，滚动结束后恢复章节吸附。
- 圆形转场：主菜单、选关和游戏页从最近点击位置进行圆形扩散切换，弹窗同步加入连续入场反馈。
- 可访问性：收起章节不参与焦点导航，支持焦点样式和 `prefers-reduced-motion` 减少动态效果。

## 第二轮质感优化

- 全面移除界面中的英文栏目标签、状态词和装饰性微文案，保留必要数字与键盘符号。
- 卡片支持随触点变化的轻微三维倾斜与局部流光，松开或移出后弹性复位。
- 主行动按钮改为流体胶囊造型，进入新页面时连续延展覆盖，而非硬切换。
- 点击关卡卡片先通过共享元素展开详情，再进入游戏，锁定状态与最佳记录清晰可见。
- 详情面板为可拖拽底部抽屉，带橡皮筋阻尼、双高度吸附、背景关闭和焦点归还。
- 选关顶部读数随真实滚动进度联动，当前卡片使用低速旋转渐变描边和克制柔光。
- 章节卡片采用交错弹簧入场，按钮按压微缩、松手超调回弹，形成统一手感。
- 减少多余科技切角、扫描线和高亮边框，放大中文信息层级，降低模板化仪表盘观感。

## 玻璃球与声音反馈

- 默认小球调整为暖黄色玻璃质感，使用透明渐变、柔和高光与内部反射，并保留红、黄、蓝染色效果。
- 小球接触实体表面滚动时播放连续、低沉且随速度变化的摩擦声，离开表面或暂停时平滑淡出。
- 小球发生实体碰撞时单独播放短促玻璃脆响，强度随撞击速度变化；传感器接触不触发声音。
- 滚动与碰撞使用独立音频节点，关闭音效后立即停止滚动声。
