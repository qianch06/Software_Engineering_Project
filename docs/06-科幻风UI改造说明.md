# 失衡空间：科幻风 UI 改造说明

## 改造目标

将游戏整体视觉调整为未来科幻风，营造深空空间站与重力控制实验室氛围，同时保留现有玩法、操作和离线运行方式。

## 主要修改

- 主菜单：加入重力能量核心、轨道动画、空间网格、扫描线与实验状态信息。
- 关卡选择：将关卡呈现为实验节点，增加节点连接、完成状态和倒映实验区样式。
- 游戏 HUD：统一深空蓝背景、冰蓝强调色、科技面板、重力圆盘和工具栏样式。
- 暂停与设置：改为半透明全息科技面板，保留原有设置功能。
- 通关反馈：加入能量核心激活动画与实验数据归档文案。
- 场景配色：调整 Canvas 中平台、机关、能量球、收集器和碎片的显示颜色。
- 全局背景：同步更新应用、页面、状态栏和安全区域的深空蓝背景色。

## 修改文件

- `App.vue`
- `pages.json`
- `manifest.json`
- `static/game/index.html`
- `static/game/style.css`
- `static/game/js/game.js`
- `static/game/js/renderer.js`

## 未修改内容

- 物理公式、重力算法、碰撞检测和物体运动。
- 通关判定、关卡数据、解锁规则、存档结构和读写逻辑。
- Accelerometer 重力感应逻辑和 Canvas 核心渲染机制。
- `manifest.json` 中的 appid、权限、包名、平台及横屏配置。
- 未增加联网功能或第三方大型依赖。

## 验证记录

- 34 项核心、运行时和可玩性测试全部通过。
- Edge 浏览器完整交互测试通过，包括选关、暂停、通关、机关、撤销、存档和横竖屏切换。
- 已检查主菜单、选关、游戏、通关及 844 × 390 横屏布局截图。
- H5 构建未在当前环境完成，原因是缺少 HBuilderX Vue3 编译插件。

## 后续真机验证

- 华为 Android 平板的横屏、安全区和文字可读性。
- 触控按钮、重力圆盘、画线、木板和缩放操作。
- Accelerometer 倾斜控制及校准。
- 菜单和通关动画的流畅度、发热与耗电情况。
- 暂停、设置、通关弹窗以及倒映章的完整显示。
